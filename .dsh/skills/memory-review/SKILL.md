# 提取和维护少量有来源的项目记忆，支持确认、修订与撤销。

先检索当前项目已有记忆。只使用已选中的一个活动记忆后端，不另建隐形副本。
明确要求记住且低风险的偏好可直接提交；含糊、敏感、关键业务结论先生成候选供确认。
每项记忆关联来源消息或资料、范围、确认状态与过期策略。矛盾记忆提出替代建议，不静默覆盖。
记忆用于个性化和上下文，不替代专业事实库。检索时只取与问题相关的少量记录。
“不要记住”禁止后续提取，但不要声称会删除 Host 会话；删除记忆、源消息与备份是不同动作。
写入、修订和撤销后根据实际工具结果回执，并可由全新会话召回测试核验。
