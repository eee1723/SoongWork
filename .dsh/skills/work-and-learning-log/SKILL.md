# 分别记录工作事实、决定、待办和学习收获，保留消息出处。

根据意图区分工作日志与学习记录，允许一次对话生成两类关联记录但不混淆。
工作日志写日期、任务、实际进展、决定、阻碍、待办与证据。未知负责人/期限留空，不能擅自编造。
学习记录写主题、理解、疑问、错题、自测与复习建议。案例先脱敏。
消息事实引用 message_id；正式规则引用文件版本。待办、建议与已完成事实分别标记。
通过受控写入工具提交，显示记录标识和待确认字段；工具失败只保留待办，不宣称保存。
